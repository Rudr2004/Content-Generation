Replit Project Prompt: AI-powered Service Page CMS Replacement
Project Description
Build a Service Page CMS to replace the current CMS content generation workflow with these capabilities:

Fixed JSON structure for service pages stored in a file, defining how all generated content should be formatted.

Admin inputs:

Service Name (mandatory)

Reference URL (optional) — system scrapes and summarizes for context

Raw data (optional) — admin’s own notes/details

SEO Keywords (manual input + AI generated option)

SEO parameters (meta title, description, alt tags)

Category & Subcategory selection and management

Use OpenAI API to generate JSON content strictly following the fixed structure and tone, based on service name + URL summary + raw data + SEO keywords.

Provide a structured JSON editor in UI allowing admins to edit generated content but preserving the fixed structure.

Support drafting, scheduling, and publishing of service pages.

Reflect category/subcategory changes dynamically in the site menu.

Ensure full backward compatibility so it replaces your existing service page CMS smoothly.

Key Features
Content generation API with prompt enforcing fixed structure and integration of URL data + admin data.

Keyword generation API for SEO.

Content editing UI with validation to keep structure.

Draft, Schedule, Publish workflow.

Category/subcategory CRUD and menu order update.

Easy migration/import from old CMS content.
